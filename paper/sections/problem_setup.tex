\section{Problem setup}
For a world $w$, let $H=(o_1,\ldots,o_L)$ be an ordered observable history with timestamps $\tau_{1:L}$, visibility/confidence, TCP state, and a candidate action $a\in A_w$. A simulator execution produces $Y_w(a)\in\{0,1\}$ using one common interception criterion. Hidden mechanism, branch, family, simulator-object identity, future trajectory, and success fields are excluded from fair model inputs. A verifier produces $s(H,a)$ for ranking candidates.

A static-only verifier depends only on current observable geometry and candidate features; an order-invariant verifier is unchanged by a permutation of history; an ordered verifier may depend on chronology. A fair analytic estimator uses only the same observable contract. A counterfactual group contains matched members with opposite execution outcomes. The final operator is $T(H)=(\operatorname{reverse}(H_{1:4}),H_{5:6})$: it reverses early branch-identifying frames while preserving the two common synchronization frames. Candidate diversity requires both outcomes within a world and branch-dependent outcome changes. World-level modulo splits separate training, validation, and test; OOD cells are disjoint parameter or mechanism regimes.
