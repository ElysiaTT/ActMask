\section{Related work}
Large robot policies such as RT-1 \cite{brohan2022rt1} and broad simulation benchmarks such as RLBench and RoboCasa \cite{james2019rlbench,nasiriany2024robocasa} address visual control and generalist-policy evaluation. They motivate careful evaluation but do not make the state-only claims tested here. Visual Foresight predicts action-conditioned futures from images \cite{ebert2018visualforesight}, while DreamerV3 uses a learned world model for control \cite{hafner2023dreamerv3}; \bench neither trains a visual predictor nor claims a learned world model.

Shortcut learning describes decision rules that succeed on standard data yet fail under changed conditions \cite{geirhos2020shortcut}. Invariant-risk and counterfactual work motivates controlled changes of distribution and comparison \cite{arjovsky2019irm,watchter2017counterfactual}. Our contribution is an execution-grounded robot-verifier construction with observable matched pairs, rather than an invariant-learning objective or a post-hoc explanation method. Time-sensitive visual representation work likewise distinguishes temporal neighbors \cite{sermanet2017tcn}, but does not test the specific static, unordered-history, and final-two-frame controls here.

CausalWorld exposes controllable causal factors in robot manipulation \cite{ahmed2020causalworld}; ManiSkill3 supplies GPU-parallelized robotics simulation infrastructure \cite{tao2024maniskill3}. \bench complements these resources by auditing a particular evaluation failure mode: whether a candidate-action verifier can be correct without using the intended temporal evidence.
