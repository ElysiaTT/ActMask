\section{Introduction}
Robot learning increasingly evaluates policies and predictors in settings described as dynamic, from visual real-robot control to large simulation suites \cite{brohan2022rt1,nasiriany2024robocasa}. Yet a dynamic label need not require a dynamic decision rule. If the current geometry, an action template, or an unordered set of past observations predicts success, a high score can coexist with failure to use temporal direction. Matching a final observation is necessary but not sufficient: a verifier can still exploit unordered motion statistics or the last two frames.

\bench asks a narrower question: given an observable state history and a candidate action, can a verifier correctly rank execution outcomes after those shortcut channels are controlled? The benchmark uses paired counterfactual worlds. Each pair preserves prescribed observable information while its execution-grounded outcome changes. This makes a failing static or order-invariant control evidence about the evaluation design, rather than a claim that any particular neural architecture possesses general physical reasoning.

Our contributions are fourfold. First, we provide a progressive counterfactual ladder that isolates static, order-invariant, short-history, and action-template shortcuts. Second, we define nonlinear paired worlds with a valid early-history swap operator and action-diverse candidate sets. Third, we provide execution-derived labels, grouped splits, OOD axes, causal controls, and leakage/diversity audits. Fourth, on the frozen state-only protocol, we report a lightweight temporal baseline against validation-selected fair analytic estimators. The scope is deliberately limited: this is neither a visual benchmark nor an end-to-end robot policy result.
