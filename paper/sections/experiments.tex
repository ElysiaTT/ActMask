\section{Experiments}
The final protocol has three procedural nonlinear families and five active ID family--mechanism cells. It uses 300 ID worlds per active cell and 100 worlds per active OOD cell, C5/C10/C20 aligned candidate views, and 92,000 candidate executions. C20 contains ten positive-direction and ten negative-direction shared interception trajectories with template variation. Training/validation/test worlds are split by fixed modulo groups; validation selects the learned and fair analytic comparators before test reporting.

We report pair-order accuracy, C20 Top-1 success, Top-3 success recall, corrected utility-gain NDCG, normalized regret, causal swap metrics, and inference latency. OOD tests change physical parameters, execution delay, or an entire held response mechanism. The main confidence interval is a grouped bootstrap over 6,000 frozen groups. Full definitions, tie behavior, and directionality are in Appendix~\ref{app:metrics}.
