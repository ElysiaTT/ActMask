# TimeArrow-Bench claim map

Working identity: **TimeArrow-Bench: Execution-Grounded Counterfactual Evaluation of Temporal Shortcuts in Dynamic Robot Action Verification**.

Alternative titles: *Do Dynamic Robot Verifiers Really Use Dynamics?*; *Counterfactual Stress Tests for Dynamic Action Verification*; *Execution-Grounded Tests for Temporal Shortcut Use in Robot Verifiers*; *From Static Cues to Nonlinear Counterfactuals in Robot Action Verification*.

Primary contributions are the benchmark ladder, valid observable pair-swap construction, execution-grounded action-diverse v2 protocol, and frozen state-only evaluation/audits. Secondary findings are the relative behavior of lightweight GRU and analytic controls. Historical 3P/3Q/3R/v1 results are diagnostics that motivate the ladder, not final proof. The claim traceability JSON is authoritative for numbers.

Prohibited claims: RGB-D or visual tracking success; real-robot transfer; end-to-end policy improvement; VLA or world-model superiority; universal physical reasoning; deployment readiness; and generalization beyond the named procedural families. Limitations are not relegated to supplementary material.
