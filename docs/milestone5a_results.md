Centroid forensics confirms a fair shortcut: it uses the complete fair
depth-backprojected world point cloud, legal camera calibration and candidate
actions, not segmentation, IDs, branch/mechanism/future/label fields, target
crops, row order or paired labels.

The required aggregation audit found 73 of 540 stored pair-order CIs do not
contain their displayed point estimate. The frozen report averages metrics
over seeds but bootstraps an ensemble-score estimator. 5A leaves all frozen
4R-v3 files untouched and suppresses those non-comparable CIs in its corrected
derived reporting note. No new relational task is generated until this
reporting issue has been reviewed as the required forensic stop condition.

Final 5A forensic decision: **D. METRIC_OR_AGGREGATION_BUG**. Milestone 5B
is not authorized. A future, separately approved continuation should recompute
the derived 4R-v3 CIs using a point estimate defined on the same estimator
(seed-average or score ensemble) before beginning relational task generation.
