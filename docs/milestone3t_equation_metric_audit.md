# Equation and metric audit

The main manuscript uses final v2 definitions only. For a world (w), candidate (a), observable history (H), and execution-derived binary utility (Y_w(a)), a verifier emits (s(H,a)). Pair-order accuracy averages the indicator that a higher score is assigned to the successful member of a matched label-flip pair; higher is better and ties receive the frozen evaluator's tie policy. Top-1 success is the utility of the highest-scoring candidate; Top-3 recall is whether a successful candidate occurs in the first three; both are higher-is-better.

Corrected utility-gain NDCG uses non-negative execution utility as graded gain with expected resolution inside equal-score blocks; higher is better. Normalized regret is oracle utility minus selected utility, normalized by oracle utility; lower is better. These definitions and the tie statement are inherited verbatim in meaning from the frozen ranking JSON/table, not redefined here.

For paired histories (H,H'=T(H)), swap accuracy measures whether the valid early-frame swap maps to the counterfactual outcome, and score-swap consistency measures whether scores exchange consistently; both are higher-is-better. Earlier-history advantage is correct-history pair-order minus final-two-only pair-order. Learned-over-analytic advantage is selected learned pair-order minus selected validation-chosen fair analytic pair-order. Static shortcut gap is temporal minus static performance on matched static counterfactuals. The grouped bootstrap interval resamples the frozen group unit (6,000 groups for full v2); it is not an IID-example confidence interval.

All scalar scores are dimensionless probabilities/accuracies in [0,1], except latency in milliseconds. History is an ordered sequence; timestamps have time units, actions and state have simulator-native units, and no equation adds incompatible quantities. The historical generic full reversal is excluded from causal-gate definitions because it is not a valid pair-swap; it is only a diagnostic in the appendix.
