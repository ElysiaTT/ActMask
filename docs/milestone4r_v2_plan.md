# Milestone 4R-v2 plan

4R remains frozen and invalid under decision E. Version 4R-v2 is a separate,
preregistered candidate-diversity repair. It preserves the three families,
visual protocol, cameras, C10 paired counterfactual construction, all eleven
partial-observation conditions, fair-input exclusions, matching checks, and
resource ceilings.

Only `SignedMovingWindowPlacement` changes: its former repeated plan is
replaced with ten branch-independent physical TCP plans spanning acquire and
release timing, lateral endpoint, and approach direction. The configuration is
written before any v2 rollout. A 64-world, no-render GPU-PhysX preprobe must
pass candidate diversity, pair-action equality, state matching, branch-change,
and index/template-leak gates before visual generation. At most two grid
repairs are allowed; otherwise the work stops for human review.
