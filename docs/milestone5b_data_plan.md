# Milestone 5B-Data plan

This fresh, no-render probe repairs 5B-0's missing observable association.
Two physical trajectories have persistent red/blue appearance markers and an
observable red target goal. Branches exchange marker-to-trajectory association
before a terminal positional merge. Every fair model can see the marker and
goal; no simulator identity, branch, target ID, label, or hidden contact mode
is exposed. The contact task additionally has an observable geometric-gap
proxy. GPU PhysX remains the sole source of C10 labels.
