# Milestone 5B-F plan

5B-F is a read-only forensic audit of frozen 5B-0 and 5B outputs. It does not
train, render, scale data, or generate simulator examples. It inventories
source hashes, analyzes raw scores by task/branch/action, checks exact and
near fair-input collisions, performs saved-checkpoint inference perturbations,
and determines which private oracle field resolves any remaining ambiguity.
