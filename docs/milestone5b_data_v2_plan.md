# Milestone 5B-Data-v2 plan

The v2 probe fixes the 5B-Data artifact by representing three anonymous
detections with balanced noncanonical order, appending an explicit red target
goal cue to every baseline feature map, and exposing appearance/gap cues only
in early frames. Current/final frames hide those cues and co-locate the two
task-relevant objects. The probe remains no-render and GPU-PhysX-labelled.
