# Milestone 4R-v3 plan

4R and 4R-v2 are frozen. Version 4R-v3 repairs the remaining MovingCube and
FixedPhase C10 candidate sets, while replaying the validated v2 placement C10.
All action plans are branch- and outcome-independent functions of common,
observable decision state and preregistered geometry. Each family must pass a
no-render GPU-PhysX C10 preprobe before clean visual regeneration is allowed.
No model evaluation is authorized before all full integrity gates pass.
